# FPGA-player 验证与上板

验证分为功能自检、TD实现和实物运行三个阶段。每个结果须记录源码版本、工具版本、运行批次与日志；编译成功、功能通过、容量满足和时序通过分别判断。已有结果见[验证状态](verification.md)，系统机制见[系统设计](design/README.md)。

## 电脑侧功能自检

从仓库根目录打开PowerShell，按层运行：

```powershell
& ./src/sim/run_tests.ps1 -Suite Common
& ./src/sim/run_tests.ps1 -Suite Storage
& ./src/sim/run_tests.ps1 -Suite Media
& ./src/sim/run_tests.ps1 -Suite Lean
```

也可用`-Suite All`运行全部24项。工具路径、单项筛选、日志和返回值见[仿真说明](../src/sim/README.md)。完整视频和整合用例耗时较长，不同时运行相同case。

| 套件 | 检查内容 | 主要通过条件 |
|---|---|---|
| Common，3项 | 复位同步、复位管理和PLL功能替身 | 复位时序和各时钟域响应符合预期 |
| Storage，10项 | SPI、SD、扇区、CDC、FAT32与原生SDRAM | 正确读数，校验/取消/反压/簇链边界、存储命令与停钟处理正确 |
| Media，4项 | BMP、WAV及FIFO | 像素/样本解析正确，边界、反压和跨域队列自检通过 |
| Lean，7项 | 文件源、控制、装载、完整视频、音频、音频缓存及核心整合 | 四方向逐像素正确，换帧隔离、音频循环、缓存边界和异常恢复符合设计 |

修改相关RTL后重跑受影响用例。正式缓存配置使用`FPGA_PLAYER_CACHED_MEDIA=1`集成场景，默认播放整合测试使用流式供数接口。各项以完整运行结果及退出码判断。

## TD综合与实现

```powershell
& ./src/td_project/run_synthesis.ps1 -Project lean_player
```

主工程入口与工具配置见[TD工程说明](../src/td_project/README.md)。脚本默认执行综合，默认模式的 `Passed`不含时序验收，须另查 `TimingMet`；可用 `-PlaceAndRoute` 继续到布线与独立hold修复，生成下载文件在TD中完成。

1. 核对目标器件、源引用及真实IP，确认测试替身未进入工程。
2. 查资源和严重诊断，确认所有RAM、PLL及SDRAM原语映射符合预期。
3. 核对SD域使用板载50 MHz、主机域83.333333 MHz、SDRAM域83.333333 MHz/210°（目标延后7 ns）、视频25 MHz及HDMI串行125 MHz五路时钟，检查两个lock及启动计数器初值。频率和相位以本次TD推导报告为准。
4. 处理域内时序、FIFO/复位跨域和SDRAM移相接口；审查IO延迟、复位恢复/移除及未约束路径。
5. 完成布局布线，重新检查最终setup/hold与约束覆盖。根据设计关系约束跨域路径，不用宽泛false path掩盖实际违例。
6. 核对板卡版本和ADC引脚，生成与该源码版本对应的下载文件，保存实现报告。

使用`run_synthesis.ps1 -Project lean_player -PlaceAndRoute`执行到最终布线检查。脚本默认只综合；布线模式的`Passed`要求最终时序通过，不能用默认综合模式的`Passed`替代。两个模式均不自动生成或下载bit。

## 实物检查顺序

器材、素材和接线按[使用说明](使用说明.md)准备，显示器接开发板 **HDMI_B**。实物操作需要连接电源、下载器、TF卡、HDMI及可选USB串口，观察画面、声音、LED和串口状态；必要时测量真实时钟与接口波形。

| 步骤 | 操作 | 预期与检查点 |
|---|---|---|
| 1. 首图 | 主工程，卡内先放一张合法BMP | SDRAM初始化、TF就绪、完整画面稳定，LED含义与主工程一致 |
| 2. 多图与轮播 | 放至少4张易区分图片，操作上一张/下一张、轮播与周期 | 图片顺序符合目录，切换不撕裂；周期按空闲显示时间计时 |
| 3. 旋转 | 对每张图操作四个方向 | 0°/180°满画面，90°/270°为居中360×480，左右边框无残留 |
| 4. 背景音 | 加入不超过4 MiB的合法WAV，首图显示并完成音乐准备后再切图 | 音乐从缓存循环播放，左右声道正确，音量和静音有效，切图和旋转时无未解释的断音；分别记录首图、音乐开始及后续切图耗时 |
| 5. UART与OSD | 逐条发送合法和非法命令 | 应答、参数和实际画面一致，状态索引与旋转含义符合使用说明 |
| 6. 异常与恢复 | 坏图、错误WAV、空卡、掉卡/重插、长按复位 | 坏图不替换有效帧；I/O收尾后可恢复，无挂死或旧事务串入 |
| 7. 长时间运行 | 重复轮播、旋转、切图与音乐循环 | 记录运行时长，检查黑行、音频欠载、HDMI故障及异常时间 |

下载前区分FPGA易失下载和Flash持久烧写，按开发板手册操作。反馈异常时同时保存工程名、源码版本、板卡/工具版本、下载文件生成时间、串口状态和现象。

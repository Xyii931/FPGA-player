# FPGA-player 当前项目状况

更新日期：2026-11-03。

## 运行状态

播放器已在HX4S20开发板上运行，当前图片与背景音乐播放正常，演示采用短WAV素材。

已确认的实板功能包括TF卡图片显示、上一张/下一张、自动轮播开关、四方向旋转、HDMI背景音乐、KEY1长按复位恢复，以及错误图片跳过。运行中拔卡后重插可恢复播放。

0°/180°显示640×480完整画面；90°/270°缩采样为360×480并水平居中，左右各留140像素黑边。操作和素材要求见[使用说明](使用说明.md)。

## 工程配置

主工程为[lean_player.al](../src/td_project/lean_player.al)，顶层为 `lean_player_top`，目标器件为 `EG4S20BG256`。

SD控制域使用板载50 MHz，SPI初始化约200 kHz、工作约6.25 MHz；主机与SDRAM时钟均为83.333333 MHz，SDRAM时钟延后7 ns；视频与HDMI串行时钟分别为25 MHz、125 MHz。

共享读卡链路使用独立FAT扇区缓存、图片整扇区接收队列及音频低水位优先调度。音频FIFO容量8192帧；图片按需清理旋转黑边，并在全部写入完成后换帧。模块结构见[源码说明](../src/README.md)和[系统设计](design/README.md)。

## 电脑侧验证

完整双控制器测试已通过：SD SPI与native SDRAM控制器RTL同时运行，完成首图加载和第二图切换；两图共写入614400个像素，209507个音频采样连续，欠载为0。图片写入阻塞、音频FIFO地址回绕及存储调度测试也已通过，具体范围见[验证记录](verification.md)。

最终布局布线在现有约束下通过时序检查，setup/hold最差余量分别为+0.120/+0.022 ns，资源容量满足要求。

两条 `PHY-7002` 严重告警仍保留，严格构建检查结果为失败。告警指向同一SDRAM原语在两个增量布局阶段的初始位置；最终55个专用连接的位置与官方参考一致，官方SDRAM包装的独立工程也能复现。告警的确切原因和完整外部IO时序尚未完成确认。

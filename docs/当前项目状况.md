# FPGA-player 当前项目状况

更新日期：2026-11-02。当前工作区位于 `init` 分支，包含尚未提交的存储链路修复、仿真和文档更新；具体版本以 Git 提交和构建记录为准。

## 已观察到的功能

在 HX4S20 开发板上，用户使用本地快速版 `lean_player_fast_6250k.bit`，观察到 TF 卡图片显示和切换、自动轮播开关、四方向旋转，以及 HDMI 背景音乐持续播放，切图期间未听到中断。KEY1 长按复位后图片和声音可恢复。用户还反馈运行中拔卡再插回正常，但尚未逐项记录画面、音频和错误码。

90°/270°画面按设计缩采样并居中，左右有黑边。实际操作、素材格式和控制说明见[使用说明](使用说明.md)。上述是本次实物观察，不代表所有文件格式、卡片和运行条件均已验证。

## 当前代码与电脑侧情况

主工程为 [lean_player.al](../src/td_project/lean_player.al)，顶层为 `lean_player_top`。当前修改包括 FAT32 挂载事务等待修复、状态跨域传递修复和 SD SPI 工作分频调整。SD 控制逻辑使用板载 50 MHz，初始化约 200 kHz，工作约 6.25 MHz。新的 SD 到目录扫描集成测试已加入测试套件。

此前快速版记录显示 `scan_chain`、`lean_audio` 仿真通过，TD 布局布线结果的 setup/hold 最差余量分别为 +0.113/+0.027 ns；仍有 SDRAM PHY-7002 位置告警。历史回归与先前版本见[验证记录](verification.md)。以上不是最终源码全量回归通过的证明，bit 与具体源码的对应关系也应以构建记录及哈希核实。

## 尚需验证和改进

- 上电后状态栏先出现，但首图出现超过 30 秒；启动速度优化暂缓。
- 串口控制、坏图片处理、音频左右声道与长时间稳定性尚待实板逐项确认。
- FPGA 断电后能否自动启动尚未确认；直接下载至 FPGA 的配置可能随断电丢失，是否写入 Flash 须另行确认。
- 换卡兼容性、外部 IO 时序及 SDRAM 位置告警仍需核查；时序余量较小，源码或约束变化后应重新检查。
- 状态栏旋转档后面的两位是临时诊断数据，不能当作可靠的分区类型或音量显示。

继续验证的操作入口见[验证与上板](验证与上板.md)和[仿真说明](../src/sim/README.md)。构建产物及个人本地记录不属于源码交付。

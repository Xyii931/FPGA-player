# FPGA-player 当前项目状况

更新日期：2026-11-03。

## 实板运行

播放器运行于HX4S20开发板，支持TF卡图片显示、上一张/下一张、自动轮播、四方向旋转及HDMI背景音乐。至少4张不同图片已成功显示，KEY1长按复位、错误图片跳过及拔卡重插恢复已有实板运行记录。

音频采用完整WAV的SDRAM缓存。启动后先显示首图，缓存完成后开始音乐；实测音乐播放期间切图和旋转明显加快，音频播放正常。演示素材为[media/](../media/README.md)中的6张BMP和20秒`SHORT20.WAV`。

0°/180°显示640×480完整画面；90°/270°缩采样为360×480并水平居中，左右各留140像素黑边。按键、UART及状态字段见[使用说明](使用说明.md)。

## 工程配置

| 项目 | 配置 |
|---|---|
| TD工程 / 顶层 | [lean_player.al](../src/td_project/lean_player.al) / `lean_player_top` |
| FPGA | `EG4S20BG256` |
| SD控制域 / SPI工作速率 | 50 MHz / 8.333 MHz |
| 主机 / SDRAM时钟 | 83.333333 MHz；SDRAM移相210°，延后约7 ns |
| 视频 / HDMI串行时钟 | 25 MHz / 125 MHz |
| 图片存储 | SDRAM双帧缓存，每帧307200个32-bit字 |
| 音频存储 | SDRAM独立4 MiB文件缓存，8192帧双时钟样本FIFO |
| 音频格式 | 48 kHz、双声道、16-bit整数PCM WAV，完整文件不超过4194304字节 |

首图提交后读取完整WAV，缓存期间保持已显示画面，新的图片请求可排队。缓存完成后的循环播放不再读取TF卡。复位或重新装卡后重新建立缓存。结构与协议见[系统设计](design/README.md)。

## 验证结果

音频缓存、WAV解码及native SDRAM集成测试通过，覆盖完整4 MiB容量、写入退休、读取边界、异常终态、取消及媒体恢复。播放中切图与90°旋转的集成测试完成921600个像素比较，5631个连续音频采样欠载为0，缓存就绪后没有新的TF音频读取。

TD布局布线采用seed 2、策略2，布线后独立执行hold修复：

| 指标 | 结果 |
|---|---|
| LUT / 寄存器 | 16280 / 19600、10616 / 19600 |
| BRAM9K / BRAM32K | 34 / 64、8 / 16 |
| 最终setup / hold WNS | +0.103 / +0.027 ns |
| ERROR / CRITICAL-WARNING | 0 / 1 |
| 资源容量 / 最终时序 | 满足 / 满足 |

实现日志保留一条SDRAM位置`PHY-7002`告警，严格构建检查`Passed=false`。测试工具、覆盖范围及诊断见[验证记录](verification.md)，复现入口见[验证与上板](验证与上板.md)。

# FPGA-player 当前项目状况

更新日期：2026-10-27（北京时间）。本说明对应 `init` 分支上以提交 `f805275` 为基线的后续修复版本，具体提交以该分支Git记录为准。

## 当前结论

**项目已完成主要功能代码、功能自检和现有约束下的布局布线，已准备主工程与HDMI诊断的候选bit，处于等待上板验证的阶段。** 当前没有正在运行的综合或仿真任务，也没有执行FPGA下载或Flash烧写。

电脑侧主要工作已完成，但还不能认定作品已经能在实物上完整稳定运行：主工程保留两条SDRAM封装位置告警，外部接口时序尚未完成完整签收，真实上电、显示、声音和稳定性均缺少板测结果。当前无需仅因LUT使用量继续删减功能。

| 背景音乐 | 选取根目录首个非空WAV目录项，校验为48 kHz双声道PCM16后循环播放，支持音量和静音 |

### TD实现结果

工具为TD V6.2.168116，目标器件为EG4S20BG256。主工程最新物理复核结果如下：

| 指标 | 结果 |
|---|---|
| 阶段 | 布局布线及独立hold修复完成 |
| LUT | 15700 / 19600，约80.1% |
| 寄存器 | 9935 / 19600，约50.7% |
| BRAM9K / BRAM32K / DSP / PLL | 32 / 2 / 2 / 2，均在容量内 |
| setup / hold最差余量 | +0.102 / +0.024 ns，总负余量均为0 |
| 错误 / 严重告警 | 0 / 2；两条均为SDRAM封装位置告警PHY-7002 |
| 判定 | `ResourceFits=true`、`TimingMet=true`；保留严重告警，严格总判定仍为 `Passed=false` |

此结果由当前源码重新综合后，复用映射数据库完成物理续跑得到；未取得修正后正式命令单进程从头到尾完整成功的记录。已修正单次运行模式下布局参数未实际生效的问题，并用TD实际参数表确认策略2和high力度生效；图形界面工程也保存了seed 1、策略2和high布局力度。布线后单独修复hold，未屏蔽hold检查。

跨域双向10 ns数据路径上限及SDRAM DQ多周期例外已核对实际覆盖。STA覆盖率为99.98%，该比例不代表尚未完整建模的外部IO时序已通过；setup余量也较小，后续修改仍需重新检查。

独立 `p0_hdmi` 诊断工程已完成布局布线，无错误或严重告警，setup/hold为+6.278/+0.022 ns，`Passed=true`。它只用于基础显示链路诊断，不验证TF卡、SDRAM或文件音频。

## 当前时钟与接口配置

| 项目 | 配置 |
|---|---|
| 板载输入 | 50 MHz |
| SD控制域 | 100 MHz |
| TF卡SPI线速 | 初始化400 kHz，工作约16.67 MHz，默认工作分频6 |
| 主机与SDRAM控制 | 83.333333 MHz，周期12 ns |
| SDRAM移相 | 83.333333 MHz，210°，目标延后7 ns |
| 视频与HDMI串行 | 25 MHz / 125 MHz |

主机/SDRAM频率调整用于改善硬SDRAM读采样余量，UART、轮播及消抖计时已同步校准；SDRAM默认以650个器件周期为实际REFRESH命令间隔上限。`O_clk_125m`等历史端口名不代表当前频率。

SD SPI从25 MHz调至约16.67 MHz，是因为带延迟测试暴露了原配置的采样风险。新SDF保守预算中，SD数据回程约需23.82 ns，当前半周期为30 ns；剩余约6.18 ns供PCB往返和额外不确定性使用。该估算采用本地SanDisk资料的14 ns卡输出上限，不能视为所有卡片和环境条件下的兼容性保证。

## 原始资料

- [HX4S20开发板手册](HX4S20开发板手册-HDL版2410.pdf)：板卡结构、器件、接口、电气与引脚信息。
- [竞赛选题指南](全国大学生嵌入式芯片与系统设计竞赛'2026选题指南_康芯.docx)：竞赛任务和提交要求的原始材料。
- [参考例程与IP资料](../reference/README.md)：实验工程、厂商HDMI核、相关手册和素材。

原始材料保留其自身标题和内容。播放器的功能、文件格式及操作协议由本项目说明与源码定义。验证结果集中在验证状态页，操作参数集中在使用说明中，设计文档负责解释实现机制。

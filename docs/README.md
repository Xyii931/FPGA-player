## 原始资料

- [HX4S20开发板手册](HX4S20开发板手册-HDL版2410.pdf)：板卡结构、器件、接口、电气与引脚信息。
- [竞赛选题指南](全国大学生嵌入式芯片与系统设计竞赛'2026选题指南_康芯.docx)：竞赛任务和提交要求的原始材料。
- [厂商HDMI依赖与IP手册](../reference/README.md)：正式工程使用的HDMI发送核、PHY、串行器及接口手册。

播放器的功能、文件格式及操作协议由本项目说明与源码定义。使用说明集中列出操作参数，系统设计解释实现机制，验证记录说明测试结果和适用范围。

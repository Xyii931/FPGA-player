# 07 验证方案

版本v1.1，2026-10-18。常量和判据以02为准；本文件定义获得证据的方法。当前不存在已完成上板验证的记录，不预勾选任何测项。

## 1. 仿真与黄金模型

使用ModelSim兼容的Verilog-2001定向激励、自检比较、超时与错误注入；不要求UVM/SVA。通用驱动检查valid等待时载荷稳定、背压不丢数据、tag正确、完成一次、复位取消无晚返回污染。

| 对象 | 必须覆盖 |
|---|---|
| 时钟/复位 | 每个域独立释放、媒体请求不复位显示/SDRAM、失锁/时钟停止 |
| SD | 可编程卡模型：初始化、SDHC/SDSC、CMD12、令牌延迟、超时、CRC错、字节边界反压 |
| FAT32 | 裸卷/MBR、活动FAT、碎片、目录跨簇、LFN校验、非法BPB/环链、三个上下文交错 |
| BMP/缩放 | 顶/底行、24/32bit、padding、截断、1×1到最大图、定点舍入和背压 |
| SDRAM适配 | IP支持的仿真模型与硬件返回相符；busy/refresh、切换、连续/随机、掩码 |
| 缓存/转场 | 槽读写互斥、晚返回generation、七效果端点/中间值、旋转/版式、连续按键 |
| 音频 | PCM码值、APT独立解码、双轨、音量/饱和、EOF、欠载包络、暂停定位、偏移 |
| OSD/设置 | 字模方向/地址、缺字/缓存冲突、层优先、跨域文本更新、断电写入各阶段 |
| 命令/状态 | MENU/UART值一致、硬拨码覆盖、告警超时/退出、看门狗空闲不误报 |

SD测试不以前置“必须先有示波器录波”为条件；卡模型先驱动开发，板上录波用于校准模型。FAT镜像可由PC脚本构造；真实卡镜像需包含被测文件、FAT和所有簇，不能默认前64 MiB总够用。

Python黄金模型独立实现协议、定点图像和APT解码。PCM应与输入归一化后逐位相等；APT与独立解码后的期望逐位相等，不能与编码前原PCM逐位相等。缩放允许同一源像素被多个目标重复使用，检查的是目标每坐标正确覆盖，不用“源坐标不重复”误判放大。

加密IP若无法在ModelSim加载，行为模型只证明自研逻辑符合**假定契约**，最终由TD支持的仿真/板测核实，不写成真实IP时序已通过。

## 2. 上板阶段

### P0 基础

- TD目标器件资源与IP分项占用，RAM块类型/映射，记录指南与手册口径差异。
- report_clocks与生成输出频率/相位；setup/hold、未约束路径、例外逐项审查，保存原始报告。
- 最小SDRAM测试：初始化前无请求、掩码、读写/刷新/切换、随机地址和连续压力；建立接受条件、返回延迟分布与持续吞吐。
- 640×480彩条/灰阶/单像素线、帧率；视频/PHY锁定与显示器识别。
- UART请求媒体软复位，旧帧与视频时序持续；KEY1全局复位允许重新握手，不能同时要求不断TMDS。
- 引脚电气及WP/HOLD、DDC、差分对与扩展口逐脚核对。测高速信号使用合适带宽/探头，不把LED分频当精度100 ppm测量。
- 720p可选实验单独记录，不阻塞640×480基线出口。

### P1 存储

至少三张不同卡：正确初始化，碎片与LFN可读，三个文件上下文交错结果逐字节或MD5与PC一致；不承诺“任意卡任意文件”无限兼容。明确FAT16/exFAT不支持提示和显式恢复扫描行为。

连续读目标≥2.5 MB/s，分别记录单流/双音轨并发平均与最大阻塞、请求长度、卡型号。若未达目标，报告对最大图装载和音频水位的影响，不能只改阈值掩盖欠载。

### P2 图像

四张基础图、非标尺寸、四旋转、五版式、七转场全部与黄金模型核对；摄像辅助检查黑屏/撕裂，受相机滚动快门和帧率限制，不能替代像素级仿真。

后台大图装载并发双源转场10 min，VIDEO_UND=0，行预取在截止前完成。BW≤80%为裕量目标，若统计方法变化需注明；平均利用率通过不能替代最大延迟通过。记录TF重载与SDRAM内合成耗时，分别报告。

### P3 音频

至少三台带HDMI音频能力的终端验证；只支持视频的显示器不作为音频失败样本。1 kHz正弦检测码值、幅度、左右声道和频率；常量CTS=25000与参考测量模式对照。无依据不测试125000为“协议值”。

双轨并发连续30 min无AUDIO_UND增长，40次切图包络正确、无异常爆音。EOF/无音轨的设计静音属正常。验证PAUSE/RESUME位置以及Δ=0、±500 ms锚点顺序；声光外测目标误差≤1输出帧，记录测量精度。低帧率手机录制不能证明小于其时间分辨率的误差。

### P4 UI与持久化

按键短/长按、编码器/红外（安装时）、UART全命令，SET/GET/菜单/实际配置一致；拨码持续覆盖与边沿事件生效。文本字符/字形全量工具校验、显示抽样、缓存冲突与Flash忙场景。

设置双备份在擦除、写头/载荷、CRC、commit各阶段受控断电；每种情况应恢复旧版或新版完整设置。再完成10次正常断电保存验证，不用十次随机拔电代替中断点覆盖。

### P5 稳定性

8 h轮播无卡死、VIDEO_UND/AUDIO_UND不增长、无错误计数累积趋势；空闲/暂停超过5 s无误看门狗复位。记录温度环境及仪器，不未经器件温度等级推导把60℃作为安全边界。供电额定条件测试为必做，拉偏仅在板卡额定范围与限流电源条件明确时进行。

掉卡保持旧帧并叠加错误，音频平滑静音；无卡重试间隔2 s，从成功重新初始化起5 s内恢复**指定测试素材**为目标，记录实际图大小/碎片。显示器热插拔目标3 s内恢复，终端握手超时单独记录。

### P6/P7 场景与交付

常驻告警已准备、UART完整命令接收后≤200 ms可见，文字/声响应分别计时，告警退出恢复保存项、剩余停留与音轨断点，转场中插播按中点规则选主项。内置演示包实际容量、CRC与无卡演示验证；素材包目标≥12图及对应音轨，基础TF四图另验收。

最终完整回归P5，构建可重现，W25Q16固化断电启动、W25Q64资源部署、TF拷贝流程均实际执行并记录。

## 3. 故障注入

| 编号 | 注入 | 预期 |
|---|---|---|
| F1 | 正在读/空闲/切换时拔卡 | 显示继续，错误提示与自动重试 |
| F2 | 坏BMP/APT/WAV、截断、非法列表 | 拒绝错误项、不提交半帧、其他项继续 |
| F3 | 显示器热插拔 | 正确失锁/恢复，不损坏媒体状态 |
| F4 | UART媒体软复位；仿真在途事务延迟 | 旧帧持续，晚返回不污染新事务 |
| F5 | 仿真输入卡住/抖动/非法IR，板上受控输入 | 超时或忽略错误，其他功能正常 |
| F6 | 转场中连续按键、改拨码、插播、保存 | 队列/覆盖规则一致，槽锁不冲突 |

不使用“随意短接GPIO”作为验证手段。需要测输入故障时仅对已确认输入脚施加合规电平，或者在仿真中注入。

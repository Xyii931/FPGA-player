# 05 音视频同步

版本v1.1，2026-10-18。统一格式、PCM幅度和接口见02 §4.4—§4.5、§5.13—§5.14。本文件定义连续采样、双音轨和播放时间线。

## 1. 数据流与采样

```text
TF → FAT32独立audio_A/B上下文 → PCM/APT双状态解码(125M)
   → A/B异步FIFO，各2048×48 bit → 音量/交叉淡化/提示音(25M)
   → HDMI核 I_audio_valid / I_audio_left_data / I_audio_right_data
```

每路FIFO12 KiB、42.67 ms，合计24 KiB；APT块重排缓存另计，不能漏入资源预算。输出为有符号PCM24，PCM16/解码后s16左移8位对齐满幅。例如s16的16384变为0x400000，s16的−32768变为0x800000。符号扩展会造成约48.16 dB衰减，不作为默认转换。

25 MHz的32位累加器每拍加8246337，进位为取样使能，平均47999.998787 Hz，量化误差−0.0253 ppm，不包含晶振偏差。只由视频域复位清零，暂停、换图、静音均保持运行。音频与ACR端口由HDMI IP手册确认在像素域；不再生成I2S后解串，外接DAC调试则另加I2S发送器及专用引脚。

## 2. ACR

```text
128*fs = f_TMDS*N/CTS
f_TMDS = 25 MHz（当前24-bit RGB模式，等于像素时钟）
N = 6144
CTS = 25e6*6144/(128*48000) = 25000
```

HDMI线上TMDS时钟为25 MHz；PHY内部125 MHz为5倍DDR串行器工作时钟，对应每通道250 Mbit/s的10-bit编码数据，**不能代入ACR公式**。先前125000推导删除。

默认常量CTS=25000，每48个采样事件发送一次ACR有效脉冲，约1 kHz。参考`audio_arc_calculate.v`恰好每48个audio_valid统计像素周期；固定采样节拍下应约25000，量化计数可能邻近波动。可保留该测量实现对照，但测量模式需跳过首个不完整窗口。

本方案采样与视频同源，晶振偏差通常共同作用于两者比值，不等于绝对采样率完全准确。IP手册公开接口未说明内部所有打包细节，P3仍要验证音调、音量、间歇静音和显示器兼容性。实验异常时先定位valid节拍、码值和包内容，不把错误时钟口径当成另一个默认档。

## 3. 双轨交叉淡化与音量

图像转场中点为默认音轨切换锚点。切换前新音轨已打开并预充，当前音轨保持供数；锚点起200 ms（9600个样本）线性混合：`g_old=1−p,g_new=p`。采用定点斜坡并在最后一个样本精确到终点，不能使用未说明单位的`acc+=96`近似。

音量0—16，增益v/16；静音精确零值，仍持续audio_valid。提示音独立ROM生成，与音轨混合时留余量，最终用宽中间值并饱和到PCM24。未指定单项音轨时使用GLOBAL bgm，均未指定才以零源淡出。单项音轨EOF平滑结束，长于图片停留时间会被下一次切换淡出，短于图片时到结束后静音。连续图片共用相同bgm时保持播放位置；bgm在EOF前预打开同文件另一上下文并交叉淡化循环，若ITEM指定其他音轨则切换，之后回到bgm时从头开始。

音频200 ms淡化窗口不要求图像转场正好200 ms；若图像已结束，声音淡化可继续。普通下一项不能覆盖尚在使用的两轨上下文，先等交叉淡化结束/安全释放，再执行合并后的切换请求。

背景音乐循环淡化期间若要切到另一条ITEM音轨，也先结束或安全取消循环淡化，再打开新目标，不建立第三条活动音轨。循环准备不足时记录迟到并平滑静音，不能宣称无条件无缝循环。

## 4. FIFO水位与欠载

| 状态 | 动作 |
|---|---|
| 启动/恢复 | 预充到至少一半（1024帧）；为目标音轨保留上下文和已播放索引 |
| <1/4（512帧） | 向TF调度器发紧急音频读；这是约10.67 ms的剩余缓冲 |
| FIFO空且本次需要该轨 | 不读空FIFO、记录AUDIO_UND事件，使用最后有效输出在64个采样内平滑降至零 |
| 恢复到一半 | 按实际策略恢复供数并渐入，记录产生的播放迟到；不谎报时间线未受影响 |
| FIFO满 | 反压解码器及文件流，不丢样本 |

静音不是把最后一个非零样本无限重复；后者产生直流或边界爆音。也不在第一次空样本处突然由大幅值跳零。欠载之后音频/视频恢复到下一可对齐锚点，不能靠重复样本修复已丢失的媒体时间。

每路缓冲只有42.67 ms，不能断言覆盖所有卡最坏延迟。P1测后台事务最大不可抢占时间，P3测双轨补给；若超限，减后台burst、提前调度或增FIFO并重新预算。

## 5. 暂停、偏移与共同时间线

### 5.1 暂停

收到PAUSE后若在图像转场中先完成转场，再冻结播放时间线。音轨短淡出，在淡出结束的实际sample_index保存位置，停止消耗该轨FIFO；恢复时可保留未消费数据，或按保存位置重读并预充。APT从所在块重解码并丢弃到精确样本位置。持续给HDMI零样本，采样发生器不暂停。

RESUME在音轨准备后重新关联时间线并渐入；不会因“FIFO自然抽空”无记录地前进85 ms。KEY3是AUTO启停，控制是否自动切图；UART PAUSE是冻结整个播放时间线，二者语义分别显示。

### 5.2 音画偏移

`Δ=t_audio_anchor−t_video_anchor`，单位ms，范围−500—+500、10 ms步进。锚点分别是图像转场中点与音轨交叉淡化开始。正值音频晚、负值音频早。

设准备完成时刻为R，默认图像锚点V必须满足转场起点≥R；若Δ<0，另要求音频锚点`V+Δ≥R`。因此可选：

```text
V = R + max(图像转场半时长, -Δ)
A = V + Δ
```

使用统一视频域计数时间（25 MHz ticks）安排A和V；先将V上取整到可提交帧边界，再由实际V计算A=V+Δ。图像事件误差记录为计划值与实际提交值之差。音频按样本边界执行。所需新图/音轨在R之前准备，A/V到来前旧画面/旧轨继续，手动负偏移可能增加最多约500 ms的等待；常驻ALERT走独立≤200 ms视觉优先路径，不应用该等待。

这通过事件调度实现±500 ms，不需要把500 ms音频塞进42.67 ms FIFO。禁止用“拉高水位”代表音频提前；预充数据不等于已经播放。

### 5.3 告警

常驻告警图在下一帧边界切入，声音20 ms内淡出当前轨再播放常驻提示音，视觉不等音频。保存正常播放项身份、剩余停留时间、所用音轨及实际sample_index，停止后关闭文件流，保留软件可重建的检查点；返回时重载/重定位、预充后从该断点渐入。完整准备期间继续告警页并显示恢复提示。若在转场中插播，按02的中点规则选择一个主项恢复其完整画面及音轨断点，不要求快照重建半途中混合画面。

## 6. 测量与验收

- 码值测试：0、正/负小幅、正满幅、负满幅及左右不同信号；PCM24与黄金结果逐位一致。
- APT与**独立APT/IMA解码模型**逐位一致；有损编码结果不与编码前PCM要求逐位相等。另报告主观听感/失真，不承诺“无差异”。
- 连续30 min无AUDIO_UND增长、无间歇静音或音调漂移；1 kHz素材频率目标1000±2 Hz，需注明录音设备误差。
- 40次切图，检查双轨预充与200 ms包络，无异常爆音；无音轨项到静音属正常，不以“任何静音即失败”误判。
- 声光锚点录制验证，默认偏移及±500 ms三类情形，标定目标≤1输出视频帧；手机录制只能作近似观察，显示器端实际延迟需同步声光采集或足够帧率设备。
- 内部样本计数差是缓冲/计划事件量，不宣传为端到端扬声器音画偏差。

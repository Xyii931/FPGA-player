## 1. SD SPI

### 1.1 初始化

| 步骤 | 行为 | 判据 |
|---|---|---|
| 1 | CS=1、MOSI=1，提供至少74个SCLK | 初始化SCLK≤400 kHz |
| 2 | CMD0，arg=0，CRC=0x95 | R1=idle |
| 3 | CMD8，arg=0x1AA，CRC=0x87 | 解析R7的电压/回显；illegal command进入旧卡兼容分支 |
| 4 | CMD55+ACMD41轮询 | SDv2设置HCS，旧卡按相应能力处理；总体超时≥1 s预算 |
| 5 | CMD58 | 检查OCR供电/就绪与CCS，不仅读取一个R1字节 |
| 6 | CCS=0时CMD16设置512 B | SDHC/SDXC块寻址不依赖此命令 |
| 7 | CMD9读取16 B CSD及CRC | 解析与CCS一致的结构0/1，取得33-bit的512 B扇区总数；成功前不发布ready |
| 8 | 切换25 MHz，CMD17/CMD18 | CCS=1用LBA，CCS=0用LBA<<9；请求不超过实际容量 |

除数表示完整周期的100 MHz拍数：初始化250，工作4。不能把“250→4”写反。卡不兼容/非法响应有明确错误，不无限循环；旧卡兼容路径需实际卡验证。

### 1.2 读取与终止

等待0xFE令牌，容忍有界数量0xFF；读取512 B及2 B CRC16。SPI CRC关闭模式也建议验证读数据CRC以发现采样边沿问题，关闭校验作为配置并记录。不能把响应后的每个0xFF都当成固定间隔。

CMD18是持续多块事务，完成后在协议要求的边界发送CMD12，处理stuff byte、R1及忙释放，再释放CS并提供所需空闲时钟。**不以随意拉高CS替代停止命令，也不先结束事务再向已脱离上下文的卡补发CMD12。** 控制器对ready反压只能在允许的字节边界停SCLK，并设暂停超时。

初始化、令牌、R1、忙释放各自有独立超时。超时阈值以协议要求和兼容性测试设置；“总线无事务”不等于卡失踪。

### 1.3 调度与速度

扇区请求count为1—128，0非法。队列4项，带context/tag。物理总线串行服务图片和两条音轨；音频低水位触发紧急补给，在下一个安全扇区边界抢占后台多块读取。后台事务的最大连续服务长度需限制，不能让128块读占用20 ms以上后才看音频。

25 MHz单线SPI理论上限3.125 MB/s；持续≥2.5 MB/s为目标，并报告测试卡、文件碎片和请求长度。640×480 RGB888 BMP约0.369 s是按2.5 MB/s计算的数据时间，不含扫描/解析。要同时测**最大一次音频供数阻塞时间**，不能只测平均速率。

CMD13探测仅在命令空闲边界每500 ms执行；读取错误也可触发无卡状态。无卡每2 s尝试重新初始化，不在CMD18数据流中硬塞探测命令。

### 2.1 引导与地址

支持MBR内FAT32分区或裸FAT32卷，512 B扇区；先验证签名与BPB字段、范围，再区分分区类型，不能只见0x55AA就当MBR。所有加法保留分区起始LBA。

| BPB偏移 | 字段 |
|---|---|
| 0x0B | BytsPerSec，必须512 |
| 0x0D | SecPerClus，合法2次幂 |
| 0x0E | RsvdSecCnt |
| 0x10 | NumFATs |
| 0x11 | RootEntCnt，FAT32应为0 |
| 0x13 | TotSec16，非零时使用 |
| 0x20 | TotSec32，TotSec16=0时使用 |
| 0x24 | FATSz32 |
| 0x28 | ExtFlags，处理FAT镜像关闭时的活动FAT选择 |
| 0x2C | RootClus |

```text
FATBase = PartitionLBA + RsvdSecCnt + ActiveFAT*FATSz32
DataBase = PartitionLBA + RsvdSecCnt + NumFATs*FATSz32
ClusterLBA = DataBase + (cluster-2)*SecPerClus
FATEntryLBA = FATBase + (cluster*4)/512
```

中间计算防溢出，检验分区、FAT、数据区均在卡容量内。FAT项取低28位，≥0x0FFFFFF8为EOC，0x0FFFFFF7为坏簇；0/1和超范围在文件链上视为错误。

### 2.2 目录与LFN

逐32 B目录项处理：name[0]=00结束，E5删除；属性0F为LFN，卷标跳过，目录/普通文件分开。LFN依据序号低5位重组，每项13个UTF-16单元，末项标志0x40，并验证短名checksum、序号连续、类型和首簇字段。终止符为UTF-16的0000，填充为FFFF，**不能把偏移13的checksum字节当字符串结束符**。

本版只接受ASCII LFN：每单元高字节必须为0，低字节为允许字符。非ASCII不截低字节伪造文件名，改用8.3别名。最多64字节路径；超长报告并跳过。文件项索引最多64个，超出提示截断；目录扫描有预算，防止恶意目录让开机永久等待。

### 2.3 三个打开上下文

图片、audio_A、audio_B分别保留first_cluster、current_cluster、offset、size、簇内扇区位置和簇检查点。调度切换只切context，不能重新open覆盖另一条音轨。读操作可带offset，暂停恢复通过检查点回到合法位置；APT从块边界解码并丢弃到目标样本。

FAT缓存以扇区LBA为键，目录缓存与播放索引另存。命中率需测试，不承诺打开任意文件固定只读三次。每次读不超过文件剩余长度，簇链遍历有卡容量/文件长度推导上限和环检测，错误归还所有在途tag。

## 4. W25Q64

唯一分区和CFG1/RLE1/DEM1格式见02 §3.2。字库完整区位槽不需索引表，所有读写检查段边界。W25Q16只用于FPGA配置，禁止素材工具误选。

SPI事务包含op、addr、len及字节流。页编程≤256 B且不跨页，扇区擦除4 KiB，写使能和BUSY轮询带超时。0x03在实际电压、器件具体型号下是否支持50 MHz由P0确认；若需高速读则显式增加0x0B及dummy时钟，不盲用50 MHz。

双备份按序号选择最新有效记录，保存写非当前副本、校验后提交commit，断电仍保留旧版本。Flash忙时OSD使用缓存字模；只串行化Flash事务，**不能停止整个100 MHz域或阻断TF卡调度**。擦写寿命及时间以确切器件手册/实测记录为准，不写未经核实的固定120 ms。

底层接收/刷新/返回、仲裁及槽读锁见02 §3.3。媒体复位不能复位控制器或清空前台缓存；后台写入取消需等待已提交事务完成。扫描端使用独立行缓存，不直接连接原始返回数据。

# FPGA-player 使用说明

播放器从TF卡读取图片和背景音乐，以HDMI输出画面与声音。按键可独立完成日常播放；UART用于修改参数和查看状态。

图片与背景音乐已通过实板运行检查。本说明定义源码对应的操作方式，完整验证范围见[验证记录](verification.md)；首次运行前应完成[验证与上板](验证与上板.md)中的电脑侧检查。

## 硬件与连接

| 器材 | 用途与连接 |
|---|---|
| HX4S20开发板，EG4S20BG256 | 播放器运行平台；使用板载50 MHz时钟及器件集成SDRAM |
| 配套电源与下载器 | 按开发板手册供电，连接板载下载接口 |
| TF卡、读卡器 | 在电脑准备FAT32文件系统和素材，再插入板载TF卡座 |
| HDMI显示器或电视、HDMI线 | 连接开发板 **HDMI_B** 输出；验证声音时需带扬声器或音频输出 |
| USB转TTL串口（可选） | TX接板端RX、RX接板端TX，并共地；电平按板卡手册核对 |

板端UART的FPGA管脚为RX F12、TX D12，外部连接器位置应查开发板手册。板级引脚定义见 [player.adc](../src/constraints/player.adc)。不需要外接SDRAM；拨码当前不参与控制，Flash不用于素材或参数保存。

## TF卡素材

卡片使用FAT32，图片和音频直接放在根目录。播放器不递归子目录，不读取文件名中的播放编号；实际播放顺序取决于FAT目录项的出现顺序。长文件名文本不参与识别，匹配使用其短目录项中的BMP/WAV扩展名。

| 素材 | 必须满足的格式 |
|---|---|
| 图片 | 640×480，24-bit或32-bit，未压缩BMP；支持正/负高度 |
| 背景音 | 48 kHz，双声道，16-bit整数PCM WAV |

最多收录16个非空BMP目录项，随后在装载时检查文件头和像素数据。遇到坏图会尝试下一项，坏图不会替换已提交画面。只选首个非空WAV目录项；该文件格式错误时报告错误，不自动改选后续WAV。背景音乐与切图独立，循环播放。

项目的 [media/](../media/README.md) 已附当前上板演示使用的6张BMP和20秒背景音乐。将这7个文件直接复制到FAT32卡根目录：

```text
/
├── PIC010.BMP
├── PIC011.BMP
├── PIC015.BMP
├── PIC026.BMP
├── PIC028.BMP
├── PIC029.BMP
└── SHORT20.WAV
```

文件名不决定播放顺序。使用本套背景音乐时，根目录保留 `SHORT20.WAV` 这一个WAV即可；也可按上述格式更换自己的素材。素材来源和署名见[演示素材说明](../media/README.md)。

## 工程与启动

主工程是 [lean_player.al](../src/td_project/lean_player.al)，顶层 `lean_player_top`，器件为 `EG4S20BG256`。可用 [p0_hdmi.al](../src/td_project/p0_hdmi.al) 做独立彩条诊断；它不读取TF卡或播放文件音频。

完成时序、布局布线及引脚核对后，在TD生成对应工程的下载文件。按板卡手册接好电源和下载器，连接HDMI设备及TF卡，再将对应文件下载至FPGA进行测试。电脑侧工程步骤见[TD工程说明](../src/td_project/README.md)。

主工程启动后初始化SDRAM和TF卡、挂载FAT32、扫描根目录并装载首图。默认开启轮播，周期5秒，旋转0°，音量4档且未静音。配置只保存在运行寄存器中，复位后恢复默认值。

## 按键与LED

| 按键 | 操作 |
|---|---|
| KEY1 | 短按释放时上一张；长按约3秒触发全局复位 |
| KEY2 | 释放时下一张 |
| KEY3 | 释放时切换轮播开关 |
| KEY4 | 释放时依次切换0°、90°、180°、270°并重新装载 |

90°/270°使用3/4最近邻采样，画面变为360×480并居中，左右各留140像素黑边。0°/180°占满640×480有效区域。

主工程LED低电平点亮，含义如下：

| LED | 点亮表示 |
|---|---|
| LED1 | SDRAM初始化完成 |
| LED2 | TF卡就绪 |
| LED3 | 已有提交成功的有效画面 |
| LED4 | 播放器报告错误或HDMI桥报告故障 |

LED2表示底层卡就绪，不能单独证明FAT32挂载成功。基础彩条诊断工程的LED含义不同，见工程说明。

## UART协议

串口设置为115200 baud、8数据位、无校验、1停止位（8N1）。命令区分大小写，使用ASCII大写，不带空格。每条命令以CR、LF或CRLF结束；等待完整应答后再发送下一条，没有硬件流控。

| 命令 | 功能 |
|---|---|
| `N` / `P` | 下一张 / 上一张 |
| `A0` / `A1` | 关闭 / 开启自动轮播 |
| `R0` / `R1` / `R2` / `R3` | 设置0° / 90° / 180° / 270°并重新装载 |
| `T01`—`T60` | 设置轮播周期1—60秒，必须输入两位十进制 |
| `V0`—`V4` | 音量：静音、1/8、1/4、1/2、原幅 |
| `M0` / `M1` | 关闭 / 开启独立静音 |
| `?` | 查询状态 |

合法设置返回 `OK`，非法或超长命令返回 `ERR`，均带CRLF。`OK`表示接受了命令，切图及旋转仍需等待文件装载和换帧完成。静音开关独立于音量档，因此 `M0` 不会改变 `V0` 的静音效果。

查询返回示例：

```text
I:02 N:04 A:0 R:3 T:0A V:2 M:1 B:0 E:0
```

| 字段 | 含义 |
|---|---|
| I | 已提交图片的0起始索引，示例为第3张 |
| N | 扫描收录图片数 |
| A | 轮播开关 |
| R | 请求的旋转档0—3 |
| T | 周期秒数 |
| V / M | 音量档 / 独立静音开关 |
| B | 图片流程忙标志 |
| E | 汇总错误码；非0需结合故障来源检查 |

**查询中的数值全部是十六进制**，例如 `T:0A` 为10秒，`N:10` 为16张；设置周期时仍发送十进制 `T10`。E为汇总错误分类：0正常，1存储或扫描故障，2图片装载错误，3音频错误，4目录或挂载错误；同时发生时按上述顺序报告。具体原因仍需结合对应模块或测试日志定位。

左上角OSD显示已提交画面的状态，图片序号从1开始，不显示周期。UART的R表示请求配置，OSD的R表示已提交旋转；重新装载期间两者可以暂时不同。

## 演示与故障定位

验证时依次检查首图显示、四张图片切换、轮播开关和周期、四方向旋转，再加入背景音检查左右声道、循环、音量与静音。用UART重复操作并观察应答和状态，最后测试坏素材、掉卡恢复和长时间运行。

无画面时先用彩条诊断区分HDMI链路与文件播放问题；主工程检查LED1/2/3及串口状态。有画面无声音时检查WAV格式、首个WAV目录项、静音和音量，并确认显示设备支持HDMI声音。切图慢时检查B是否仍忙，不将命令应答当作装载完成。具体预期和通过条件见[验证与上板](验证与上板.md)。

## 实板运行

HX4S20开发板已完成图片显示、按键切图、轮播开关、四方向旋转和短WAV背景音乐播放检查，当前播放正常。长按复位后图片和声音可恢复，错误图片会被跳过，拔卡重插可恢复播放。

实板检查使用现有TF卡和显示设备；实际加载耗时、UART、左右声道及长时间运行尚待专项记录。

## 功能测试

| 测试范围 | 结果与覆盖 |
|---|---|
| SD SPI与native SDRAM完整联合测试 | 首图加载与第二图切换通过；每图307200次像素写入、1801个数据扇区；209507个音频采样连续，欠载为0 |
| 图片写入阻塞 | 暂停图片写入220 ms期间10560个音频采样连续，欠载为0；解除阻塞后整帧307200像素比较通过 |
| 真实TD RAM模型 | 18000个连续音频采样覆盖8192帧FIFO两次地址回绕，包含100 ms上游暂停；声道、循环、音量、静音及ACR检查通过 |
| FAT查询后重新仲裁 | 音频优先服务检查通过，避免音频等待已暂停的图片数据扇区 |
| 文件源、挂载与目录扫描 | 对应存储服务及集成自检通过 |

完整联合测试采用Verilator 5.020二态模型和实际控制器RTL，保留初始化周期、时钟及卡端和连线延迟，并检查显示采样、活动帧保护、写入退休与存储协议。真实RAM测试采用ModelSim-Altera 10.3c及TD提供的RAM模型。其余功能场景的运行入口和模型选择见仿真说明。

功能模型不覆盖厂商加密HDMI核、PLL硬件相位、真实卡片电气特性或物理音质；仿真耗时不作为板卡加载速度。最终源码的全部24项自检尚未统一复跑。

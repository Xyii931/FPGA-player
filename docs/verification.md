# FPGA-player 验证记录

更新日期：2026-11-03。运行配置见[当前项目状况](当前项目状况.md)，复现命令见[仿真说明](../src/sim/README.md)。

## 实板运行

HX4S20开发板上已完成图片显示、按键切图、轮播开关、四方向旋转和短WAV背景音乐播放检查，至少4张不同图片成功显示。KEY1长按复位后图片和声音可恢复，错误图片会被跳过，拔卡重插可恢复播放。

SDRAM音频缓存配置的实测顺序为先显示首图、再开始音乐。音乐开始后，切图和旋转明显加快，音频播放正常。实板素材为6张640×480 BMP和20秒`SHORT20.WAV`。

## 功能仿真

| 测试范围 | 结果与覆盖 |
|---|---|
| WAV缓存播放 | 4900个采样逐帧比较通过，欠载为0；缓存文件读取1次，共2844字节，循环播放无TF重读 |
| ModelSim与TD RAM | 左右声道、循环、音量、静音、ACR及100 ms上游暂停检查通过 |
| 缓存与native SDRAM | 字节打包、尾字补零、写入退休、非对齐与边界读取、Begin失败、文件错误、offset断裂、取消及媒体恢复通过 |
| 完整缓存容量 | 写入4194304字节，最后合法字地址2097151及尾部读取检查通过 |
| 播放器与native SDRAM集成 | 首图、第二图及90°旋转共比较921600个像素；5631个连续采样、欠载为0；缓存就绪后TF音频读取不增加，拔卡重插后重新缓存并恢复播放 |
| 图像扫描与旋转 | 四方向完整视频回归完成4×307200个输出像素比较 |
| SD与文件服务 | SPI字节、SD PHY、扇区读取、FAT32挂载及目录扫描对应自检通过 |

缓存与完整帧集成使用Verilator 5.020、实际native SDRAM控制器RTL和独立器件模型；集成的SD侧为功能扇区端点。缓存单元短测试和TD RAM音频测试使用ModelSim-Altera 10.3c。WAV采样测试使用可逐样本核对的2844字节数据，完整缓存容量由独立4 MiB测试覆盖。

测试集共25项，分为P0、Storage、Media和Lean四个套件。正式音频缓存集成场景由`FPGA_PLAYER_CACHED_MEDIA=1`选择；模型范围及工具参数见[仿真说明](../src/sim/README.md)。厂商加密HDMI核、PLL相位和接口电气由TD与实板检查。

## TD实现

验证环境为Anlogic TD V6.2.168116，目标器件`EG4S20BG256`。布局使用seed 2、策略2，布线后独立执行`fix_hold`；生成bit前重新导入最终数据库，执行`check_io`并复核最终时序。

| 指标 | 使用 / 容量或结果 |
|---|---|
| LUT | 16280 / 19600 |
| 寄存器 | 10616 / 19600 |
| BRAM9K / BRAM32K | 34 / 64、8 / 16 |
| DSP / PLL | 2 / 29、2 / 4 |
| 最终setup / hold WNS | +0.103 / +0.027 ns |
| ERROR / CRITICAL-WARNING | 0 / 1 |
| ResourceFits / TimingMet | true / true |
| 严格构建检查Passed | false |

保留的`PHY-7002`严重告警指向SDRAM原语在增量布局阶段的初始位置。资源和最终时序满足现有约束，严格诊断状态单独记录。外部IO时序审查按[验证与上板](验证与上板.md)执行。

仿真结果保存于`src/sim/build/`，TD实现报告保存于`.local/td-build/`。复现时保存源码版本、工具版本、运行参数及日志。
